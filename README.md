# Week 2 – Network Discovery & Host Scanning

**Cybersecurity Internship | NETWORKWALKS | Batch B084**

## Overview
This repository contains my Week 2 practical work as part of the NETWORKWALKS Cybersecurity Internship.

The objective of this task was to identify live hosts within a local network using Nmap and its graphical interface, Zenmap.

## Tools Used
- Nmap
- Zenmap
- Windows Command Prompt

## Practical Tasks
1. Identified the local IP address.
2. Identified the LAN subnet and subnet mask.
3. Performed a Ping Scan using Zenmap.
4. Discovered active hosts within the local subnet.
5. Identified the IP addresses of live hosts.
6. Examined available MAC address information.
7. Explored network topology visualization.
